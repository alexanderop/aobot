# aobot

AI coworkers for our company. Each Bot has a role, its own computer (a browser, a shell and a folder),
and guardrails: every action it takes is checked and recorded before it happens.

Inspired by [CopilotKit OpenBot](https://github.com/CopilotKit/openbot), rebuilt on our own stack so it
needs no external service and can run entirely inside our AWS account.

**Status:** planning. Nothing is implemented yet. The plan lives in [`docs/`](docs/README.md).
