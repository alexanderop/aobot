# 4. Solution strategy

| Idea                                          | Serves                  | How                                                                                                                                      | Decision                                                                                                                                                              |
| --------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **One door for every action**                 | Safety, accountability  | The agent can only ask; the gateway checks the grant, then the rules, writes an audit row, and only then forwards to a computer          | [ADR-7](09-architecture-decisions.md#adr-7--fail-closed), [ADR-11](09-architecture-decisions.md#adr-11--every-audit-row-names-its-initiator)                          |
| **The rule is in the graph, not in a review** | Safety, simplicity      | Only the `gateway` feature may depend on `computers`. oxlint enforces the feature graph in `policy.ts`, so no other code can reach one   | [quality gates](../quality-gates.md#feature-based-architecture)                                                                                                       |
| **Swappable providers behind small services** | Portability             | `AgentRuntime` (`api` now, `acp` later) and `Computers` (`docker` now, `ecs`, `k8s`, `mac` later) are Effect services chosen by `Config` | [ADR-2](09-architecture-decisions.md#adr-2--the-think-act-loop-is-a-provider), [ADR-6](09-architecture-decisions.md#adr-6--a-computer-is-only-ever-a-url-and-a-token) |
| **Effect v4 on the server**                   | Safety, accountability  | Every failure is a typed error, so every gateway path is visible to the compiler. `Effect.fn` names give one span per operation          | [ADR-3](09-architecture-decisions.md#adr-3--effect-v4-on-the-server)                                                                                                  |
| **One schema for the wire**                   | Simplicity              | `packages/domain` defines `ChatEvent` and `ChatRpcs` once. Server and page encode and decode the same Schema                             | [ADR-12](09-architecture-decisions.md#adr-12--ag-ui-events-over-effect-rpc-read-through-atoms)                                                                        |
| **Stream everything, watch for silence**      | Responsiveness          | The answer streams as AG-UI events. A stall watchdog and a step cap end a turn that goes nowhere                                         | [Section 6](06-runtime-view.md)                                                                                                                                       |
| **The page as text, not screenshots**         | Simplicity, cost        | Computers return the accessibility tree with a ref per element. No vision model needed                                                   | [ADR-5](09-architecture-decisions.md#adr-5--the-page-as-text-not-screenshots)                                                                                         |
| **Local first, cloud ready**                  | Portability, simplicity | Compose today. Two switches and a database change later, never a code path that checks where it runs                                     | [Section 7](07-deployment-view.md)                                                                                                                                    |
| **Vertical slices, done means demoed**        | Simplicity              | Each ticket ends in a browser demo that `vp run verify <ticket>` replays                                                                 | [testing](../testing.md)                                                                                                                                              |
