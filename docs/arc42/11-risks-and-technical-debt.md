# 11. Risks and technical debt

## Technical debt in what exists

| #   | Gap                                   | What happens                                                                                                                                                                                             | Way out                                                                                                                        |
| --- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| D1  | **A reload during a live run**        | `Chat.open` says a run is in flight, so the page opens as running, but it cannot follow a stream it did not start. From the code: it shows the Bot as answering until the next reload after the run ends | Let `Chat.open` (or a new `Chat.follow`) replay the run's events so far and stream the rest                                    |
| D2  | **SQLite and an in-memory run guard** | Correct for one server process. A second replica would have two guards and two database files                                                                                                            | Postgres and a shared lock with the cloud move ([E5-1](../backlog/E5-aws/E5-1-aobot-in-our-aws-account.md))                    |
| D3  | **CI does not run `verify`**          | CI runs `vp run check` only. The browser demos (tier 4) run on a developer's machine, with Docker and `agent-browser`                                                                                    | A CI job with Docker and `agent-browser` ([E0-4](../backlog/E0-walking-skeleton/E0-4-quality-gates-and-ci.md))                 |
| D4  | **No sign-in**                        | Compose binds the ports to loopback, so only the local machine reaches the server. Anyone there can chat, and every conversation is visible to whoever has its id                                        | [E3-1](../backlog/E3-people/E3-1-sign-in-with-company-sso.md), [E3-2](../backlog/E3-people/E3-2-my-conversations-only-mine.md) |
| D5  | **No telemetry export**               | Spans have names (`Effect.fn`) but go nowhere; Grafana in Compose stays empty                                                                                                                            | [E0-2](../backlog/E0-walking-skeleton/E0-2-one-chat-turn-is-one-trace.md)                                                      |
| D6  | **The mock model is a one-off**       | `verify/mock-model.ts` answers every request with one sentence. Tests cannot script tool calls through it yet                                                                                            | [E0-3](../backlog/E0-walking-skeleton/E0-3-a-scripted-model-for-tests.md)                                                      |
| D7  | **The docs site is not built in CI**  | `vp run check` tests the front-matter of every page but does not build `apps/docs`, so a page Starlight cannot render is found only when someone builds the site                                         | Add `vp run @aobot/docs#build` to CI once it stays fast                                                                        |

## Risks in the plan

| #   | Risk                                 | Why it matters                                                                                                                                                                 | Mitigation                                                                                                                                                              |
| --- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | **Prompt injection from pages**      | A page can tell the Bot to do something its person never asked for                                                                                                             | Untrusted-data envelope ([ADR-10](09-architecture-decisions.md#adr-10--outside-content-is-untrusted-data)), grants, rules that fail closed, approvals for risky actions |
| R2  | **Instance metadata on AWS**         | On AWS a shell can reach `169.254.169.254`, which hands out the machine's IAM role. OpenBot found this the hard way: [PR #620](https://github.com/CopilotKit/openbot/pull/620) | IMDSv2 with a hop limit of 1 on every node, and that range blocked in network policy ([E5-3](../backlog/E5-aws/E5-3-computers-cannot-reach-aws-credentials.md))         |
| R3  | **The Docker socket is root**        | The `docker` computer provider talks to the Docker socket, which is root on that machine                                                                                       | Fine on a laptop; replaced by the ECS or Kubernetes API on AWS ([E5-2](../backlog/E5-aws/E5-2-computers-as-ecs-tasks.md))                                               |
| R4  | **A CLI acting outside the gateway** | `acp` runs Claude Code, Codex or OpenCode, whose own tools could reach the disk or a shell                                                                                     | Built-in tools off, every out-of-band request refused and audited, a contract suite each CLI must pass ([section 5](05-building-block-view.md#agentruntime))            |
| R5  | **Private and internal addresses**   | A Bot's browser could reach internal services through DNS tricks or alternative IP spellings                                                                                   | Resolve, check every address in every spelling, connect only to the checked address ([section 8](08-crosscutting-concepts.md#security))                                 |
| R6  | **Scope for one developer**          | Six epics are a lot for a learning project                                                                                                                                     | Vertical slices with a demo each, so every finished ticket is usable on its own                                                                                         |
