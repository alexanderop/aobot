# Later

Not planned yet. Each becomes an epic when the core above is in use.

| Idea                             | What it is                                                                                                                                                                                         | Reference in OpenBot                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Generative UI                    | Bots answer with charts, tables and cards instead of only text                                                                                                                                     | Components gallery, `app/src/components/gallery/`                   |
| Bot-to-Bot handoff               | A Bot asks another Bot, under a grant, audited with the asking Bot as the cause                                                                                                                    | Groups and handoffs in `docs/architecture.md`                       |
| Routines                         | Scheduled turns that run as their owner; audit marks them as "nobody watching"                                                                                                                     | `docs/routines.md`                                                  |
| App integrations                 | MCP tools from Composio, Arcade or our own servers, granted per Bot and per tool                                                                                                                   | `docs/plugins/`                                                     |
| Bots and rules in the UI         | Admins create Bots and edit rules without a deploy                                                                                                                                                 | `/bots`, admin policy                                               |
| Memory                           | Facts a Bot keeps about a person across conversations                                                                                                                                              | `server/src/memory/`                                                |
| Recorder                         | Learn a workflow from a person's own browser in the desktop app                                                                                                                                    | `extension/`, OpenBot Recorder                                      |
| Audit export and retention       | CSV export, retention period, deletion                                                                                                                                                             | `docs/architecture.md` § Taking the trail out                       |
| Rule dry-run and replay          | A new rule runs in `dry-run` first: decisions are recorded, not enforced, and it is replayed over past audit rows to show what it would have refused                                               | `server/src/computer/policy-dry-run.ts`                             |
| Live rules and kill switches     | Rules change without a restart on every replica (Postgres `LISTEN`, re-read on reconnect); admin switches turn off cloud computers, network or MCP during an incident, failing closed while unread | `computer/policy-listener.ts`, `admin/controls.ts`, `admin/gate.ts` |
| SCIM deprovisioning              | Disabling someone in the IdP ends their sessions, blocks the address and offboards their computer, without anybody clicking Remove                                                                 | `server/src/auth/scim.ts`                                           |
| Standing instructions per person | Up to 4,000 characters about how a person likes to work; the role decides what a Bot does, these decide how                                                                                        | `server/src/user-instructions.ts`                                   |
| Narrowing the tool list          | Once a Bot has many MCP tools, a skill picker offers only the relevant ones per message (not below twelve tools)                                                                                   | `docs/architecture.md` § Which tools a run is offered               |
| Getting past bot checks          | Web Bot Auth request signing and a residential or ISP proxy, both opt-in                                                                                                                           | `docs/configuration.md` § Getting past bot checks                   |
| Full Mac control                 | Other apps, mouse and keyboard outside Chrome, with Accessibility permission                                                                                                                       | –                                                                   |
